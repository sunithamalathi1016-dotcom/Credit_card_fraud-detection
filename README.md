# 💳 Credit Card Fraud Detection

## 📌 Overview
This project uses Machine Learning to detect fraudulent credit card transactions. It includes data preprocessing, exploratory data analysis (EDA), model training, and performance evaluation to classify transactions as legitimate or fraudulent.

## 🛠 Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- TensorFlow/Keras (optional)
- Jupyter Notebook

## 📂 Dataset
The dataset contains anonymized credit card transactions with:
- **Time**
- **V1–V28** (PCA-transformed features)
- **Amount**
- **Class** (0 = Legitimate, 1 = Fraud)

## 📊 Workflow
1. Load Dataset
2. Data Preprocessing
3. Exploratory Data Analysis
4. Feature Scaling
5. Train-Test Split
6. Model Training
7. Model Evaluation
8. Fraud Prediction

## 📈 Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1 Score
- ROC-AUC
- Confusion Matrix
